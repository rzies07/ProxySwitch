# ProxySwitch

Минималистичный, нативный системный переключатель прокси для Windows.
Написан на C# (.NET Framework WinForms), компилируется штатным csc.exe без внешних зависимостей.

---

## О проекте

ProxySwitch — компактная утилита для быстрого переключения системного прокси-сервера Windows, мониторинга сетевых маршрутов и проверки доступности интернет-ресурсов.

Интерфейс выполнен в строгом Solid Minimal дизайне (темная монохромная палитра, субпиксельный шрифт Segoe UI ClearType, отсутствие визуального шума). Утилита не создает фоновой нагрузки и работает полностью автономно без тяжелых сред выполнения.

---

## Ключевые возможности

* Мгновенное переключение маршрута: Управление системным прокси через WinINet API (InternetSetOption) без перезапуска браузеров, мессенджеров и консолей.
* Глобальный хоткей (Ctrl + Shift + P): Включение и отключение прокси из любого окна или полноэкранного приложения.
* Фоновая работа в трее: Кнопка закрытия (X) сворачивает программу в область уведомлений возле часов, сохраняя стабильное сетевое соединение.
* HTTP-чекер доступности: Прямые HTTP-запросы к сервисам (Google, OpenAI, Anthropic, YouTube, Discord, Telegram, VK) через активный туннель вместо ICMP-пинга для проверки реальных блокировок.
* Тест скорости (Speed Test): Измерение реальной пропускной способности канала через тестовый пакет данных (Cloudflare CDN) в Мбит/с.
* Менеджер профилей и автосортировка: Хранение серверов с тегами (Tag [IP:PORT]) и параллельный опрос узлов с упорядочиванием по минимальной задержке.
* Список исключений (Proxy Override): Управление перечнем адресов и масок (localhost, 127.0.0.1, *.ru, <local>), идущих в обход туннеля.
* Автоматический Failover: Периодическая фоновая проверка шлюза. При сбое сервера системный прокси отключается автоматически, исключая потерю связи.
* Geo-IP детекция: Определение реального выходного IP-адреса и кода страны в реальном времени.
* Автозагрузка: Опциональная интеграция в реестр автозапуска Windows (HKCU\...\Run).

## Быстрый старт и сборка

Для сборки не требуются Visual Studio, пакетные менеджеры или внешние SDK. Используется встроенный в систему компилятор csc.exe.

1. Клонирование репозитория:
   git clone https://github.com/rzies07/ProxySwitch.git
   cd ProxySwitch

2. Компиляция:
   Запустите файл BuildAndRun.bat. Скрипт автоматически найдет компилятор csc.exe, вошьет иконку app.ico и соберет исполняемый файл.

---

## Управление

* Быстрое переключение: Ctrl + Shift + P (глобальный хоткей)
* Свернуть в трей: Кнопка X в правом верхнем углу
* Полный выход: Правый клик по иконке в трее -> Exit
* Сортировка серверов: Кнопка SORT
* Тест скорости: Кнопка SPEED TEST
